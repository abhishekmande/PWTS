1. Types of Programing Langauge
-> there are 2 types of PL, 1. Static PL & 2. Dynamic PL, further each Staitc PL and Dynamic PL has 
	Functional PL and OOPL
	
	what is Static PL and Dynamic PL?
	-> whenever we write a code, and at the time of writing code it is throwing an error is Static PL,
	on writing the code and during execution of code if it throws error then it is called Dynamic PL,
	javascript file is Dynamic PL and typescript file is Static PL
	Static PL: TS, JAVA, .net
	Dynamic PL: JS, Python
	
	Functional PL: which doesnt require us to create a class, eg: JS, TS, Python
	OOPL: mandatory to create a class, eg in java to write "System.out.println("test")" we need to write in a class,
			Java, .net, c#
