git(version control system)- tool used to track the code changes in local system
github- (one of the version control tool) online platform where git repository are stored and helps us in term of collabartion, inshort we post changes from local to remote repo 

1. You are the first employee to start test automation with no repo available on the github

-> Step0: create a new repo on the version control tool ie Github
	Step1: create a project in vs code(local system) and write the test cases inside your local system
	Step2: In terminal of VS code type "git init"- this cmd initalizes the new .git repo inside the local system
			this above cmd "git init" creates a ".git" folder inside the local system
	Step3: in terminal type "git add ." this cmd will add all the files that you have changed/added in Project local system into ".git" folder of local system
	Step4: So now the changes what we have added in the local git ie ".git" now we need to commit the same changes so we use below cmd,	
			cmd: git commit -m "First Commit"
			
	In local,If want to create a new branch and switch to that branch use cmd: git checkout -b branchname, to check branch is created or currently on which branch use cmd: git branch 
	
	Step5: to connect the local repo to remote repo use cmd, this is a 1 time step:
		cmd: git remote add origin https://github.com/abhishekmande/gitdemo.git
		
	Step6: now to push the changes from local to remote
		cmd: git push -u origin branchname(the local branchname where we are)
		
	//Now in the above steps we have updated the repo of github, but after if someone else updates the repo of github and we want those updates in our local 
		and then to post our changes from the local to the github repo:
			
			Step A: git checkout master //
			Step B: git pull // It will pull all the latest changes from the remote repo to local repo
			Step C: git checkout -b branchName - Create a new branch going forward for all the new task
			Complete writing the test case and follow the steps from #3, #4 and #6(change the branch name)
		
		
git branch -M master: This command is mainly used to rename the current branch to master.
git checkout -b main: this cmd is to create the new branch named main and to switch to this branch
git checkout branchname(master): to switch to the branchname(master) 
git branch: to get list of all branches
