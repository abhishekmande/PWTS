git(version control system)- tool used to track the code changes in local system
github- (one of the version control tool) online platform where git repository are stored and helps us in term of collabartion, inshort we post changes from local to remote repo 

1. You are the first employee to start test automation with no repo available on the github
-> Step0: create a new repo on the version control tool ie Github
	Step1: create a project in vs code(local system) and write the test cases inside your local system
	Step2: In terminal type "git init"- this cmd initalizes the new .git repo inside the local system
			this above cmd "git init" creates a ".git" folder inside the local system
	Step 3: in terminal type "git add ." this cmd will add all the files that you have changed/added in local system into in ".git" folder of local system
	Step4: So now the changes what we have added in the local git ie ".git" now we need to commit the same changes so we use below cmd,	
			cmd: git commit -m "First Commit"
			
	In local,If want to create a new branch and switch to that branch use cmd: git checkout -b branchname, to check branch is created or currently on which branch use cmd: git branch 
	
	to connect the local repo to remote repo use cmd:
		cmd: git remote add origin https://github.com/abhishekmande/gitdemo.git
		
	Step5: now to push the changes from local master branch to remote master branch
		cmd: git push -u origin master
		
		
git branch -M master: This command is mainly used to rename the current branch to master.
